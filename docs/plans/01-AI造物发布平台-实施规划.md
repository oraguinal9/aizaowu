# AI项目发布平台 — 实施规划

## Context

素人开发者用AI做出了项目，但不知道在哪发布、怎么推广。GitHub国内访问不稳定，ProductHunt门槛太高。市面上缺少一个**中国素人AI项目的发现和展示平台**。

类比传奇私服发布平台：私服主需要曝光，玩家需要发现 → AI创作者需要曝光，用户需要发现。同一套"流量分发+信任中介"的逻辑。

**核心定位**：纯目录+社区，不托管项目代码，项目链接指向外部URL。

## 3. 数据库设计

共5张表，与灵犀解梦模式一致：UUID主键、auth.users外键、DB函数处理计数。

```sql
categories     — 分类（slug, name_zh, icon, sort_order）
projects       — 项目（slug, name, tagline, description, url, screenshots[], 
                 category_id, tags[], status, vote_count, comment_count, 
                 submitter_id, created_at, published_at）
votes          — 投票（user_id可空, ip_address可空, project_id）
                 UNIQUE约束分两种：user_id+project_id（登录用户），ip_address+project_id（匿名用户）
                 触发器自动更新vote_count
comments       — 评论（project_id, user_id, parent_id可空, body）
                CHECK最多2层嵌套
rate_limit_log — IP限流日志（复用灵犀解梦模式）
ip_votes_daily — 匿名投票日限额（ip_address, date, count），每日每IP最多3票
```

**关键设计**：
- `vote_count`/`comment_count` 反范式化到projects表，避免排行查询JOIN COUNT
- **直接发布**：状态默认 `published`，事后巡查发现问题 → `hidden`（软删除）。不做pending审核流程
- **混合投票**：登录用户正常投票（user_id），未登录用户基于IP投票（每日3票上限），两种模式互斥
- 中文搜索用 `pg_trgm` 三元组模糊匹配（不用zhparser，太重）
- RLS策略：published项目公开可读，hidden仅admin可见；投票/评论需登录或IP验证

## 4. MVP功能范围（4周）

### Sprint 1：基础框架（5天）
- Next.js初始化，Tailwind v4 + @theme配色
- Supabase建表迁移，seed 8个分类 + 10个种子项目
- 基础Layout（Header/Footer），globals.css
- Supabase client工具（server/browser/admin三个client）
- robots.txt + sitemap基础SEO

### Sprint 2：核心页面（5天）
- 首页：最新项目网格 + 本周热门侧边栏
- 分类页：`/categories/[slug]`，排序+分页
- 项目详情页：`/projects/[slug]`，截图画廊+Markdown描述+元信息
- 提交页：`/submit`（auth-gated），多步表单+截图上传至Supabase Storage
- 登录页：GitHub + Email magic link

### Sprint 3：互动功能（5天）
- 投票系统：混合模式 — 登录用户直接投票，未登录用户IP投票（每日3票上限）。optimistic UI按钮
- 评论系统：二层嵌套评论，Markdown输入，需登录
- 排行榜：日/周/月/总榜，PostgreSQL窗口查询
- 搜索：pg_trgm模糊搜索 + 客户端即时搜索建议
- 管理面板：隐藏页面，巡查已发布项目（发现问题→hidden），查看投票/评论异常

### Sprint 4：打磨上线（5天）
- JSON-LD结构化数据（SoftwareApplication schema）
- OG/Twitter卡片动态生成
- 移动端适配
- 性能优化（Lighthouse > 90）
- VPS部署（PM2 cluster + Nginx反向代理 + Let's Encrypt SSL）
- 提交Google/Bing/Baidu站长平台

- **JSON-LD**：SoftwareApplication（详情页）、BreadcrumbList、CollectionPage、ItemList
- **Sitemap分片**：静态页 + projects-0.xml / projects-1.xml ...
- **Baidu专项**：百度站长平台提交 + 自动推送API + 百度统计 + Baidu-OG标签
- **内链**：相关项目 + 面包屑 + 分类页链接所有子项目 + Footer链接所有分类

// API Route Handler 模式（来自灵犀解梦）
export async function POST(request: NextRequest) {
  try {
    const body = await request.json();
    // validate → business logic → DB → response
    return NextResponse.json({ success: true, data: { ... } });
  } catch (error) {
    console.error("...", error);
    return NextResponse.json({ success: false, error: "..." }, { status: 500 });
  }
}

// 限流模式（来自灵犀解梦 rate_limit_log 表）
// 统计时间窗口内IP请求数 → 超限返回429 → 记录成功请求

// 环境变量命名（来自灵犀解梦）
// NEXT_PUBLIC_SUPABASE_URL / NEXT_PUBLIC_SUPABASE_ANON_KEY (客户端)
// SUPABASE_SERVICE_ROLE_KEY (服务端，无NEXT_PUBLIC_前缀)

// 混合投票模式（本项目新增）
// - 登录用户：votes表记录user_id，UNIQUE(user_id, project_id)
// - 匿名用户：votes表记录ip_address，查ip_votes_daily判断日限额
//   → 未超限：插入vote + upsert ip_votes_daily count+1
//   → 超限：返回 { canVote: false, reason: "今日匿名投票已达上限(3次)，登录后不限次数" }
// - 去重：同一IP对同一项目只能投一票 UNIQUE(ip_address, project_id)
